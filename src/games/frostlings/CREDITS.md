# Frostlings — credits
- Design, code, creature models, world, procedural audio fallback: Iceberg Game Maker 2 (final batch, 2026-11-15).
- Sound: Iceberg Sound Designer 2 pack → `./sfx/<cue>.ogg` + `cues.json` (cue list: `designs/frostlings-cues.md`, 35 cues).
  Every cue has a procedural Web Audio fallback, so the game is fully voiced before the pack lands.
- Patterns borrowed from Snowball Siege / Knockout Floes (particles, text pops, HUD-built-once, one-time BB milestones)
  and the platform multiplayer API (`docs/MULTIPLAYER_API.md`: events for pals/emotes/duels; avatars are automatic).
- Three.js (MIT).
