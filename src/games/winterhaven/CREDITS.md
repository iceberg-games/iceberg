# Winterhaven: credits

Everything in this game is Iceberg original. Nothing comes from Roblox or third parties.

- **Map:** Iceberg Set Builder's Winterhaven set (`sets/winterhaven`): the layout (`layout.js`, copied as-is) and the procedural Three.js scene (`scene.js`, ported, with `lib/` helpers for batching, sky and snow). That covers the cabins, the town tree, the castle, the pines, the stalls, the cave, the GLSL patterns, and the sky with aurora and moon.
- **NPC roster:** Iceberg Set Builder's `npcs.js` (32 villagers; ids shared with Cosmetics), copied as-is.
- **Game-side work (Iceberg Game Maker):** collision, villagers, quest items, the Frostgate Run gates, the HUD and the menu card.
- **Music:** "Winterhaven" in-game loop by the Iceberg Sound Designer. It's an original synthesized 40 s seamless loop (`site/public/audio/winterhaven/`).
- **SFX + ambience:** Winterhaven SFX pack by Iceberg Sound Designer 2. It's original synthesis with no samples: NPC voices, quest cues, menu cues (`sfx/`, inlined) and three ambience loops (`site/public/audio/winterhaven/ambience_*.ogg`).
- **UI sounds:** the Iceberg "Frost Glass" UI set (shared `src/audio/uiSounds.js`). Small procedural Web Audio chimes are used for collect, gate and win.
